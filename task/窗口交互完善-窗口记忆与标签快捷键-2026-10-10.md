## 二、改动清单

### 1. 窗口状态记忆（新增）
- 新增 `electron/main/windowState.ts`：`window-state.json` 存位置/尺寸/最大化；resize/move/maximize 事件 **500ms 去抖写入**、关窗时**立即补写**；恢复时用 `screen.getAllDisplays()` 做越界校验（可见面积阈值 120×40，越界则居中），尺寸超出目标显示器工作区则收缩；全屏不记忆（与 shell-rs 一致）。
- `electron/main/index.ts`：创建窗口时套用记忆值，`show:false` + `ready-to-show` 再显示并在此时最大化，消除启动闪跳。
- `electron/main/store.ts`：设置项新增 `rememberWindowSize` / `rememberWindowPosition`（默认 true）与主进程读取入口 `getStoredSettings()`。

### 2. 窗口交互快捷键
- **F11 全屏**（`win:toggle-fullscreen` IPC + `win:fullscreen` 状态回传）；标题栏最大化按钮在全屏时切换为"退出全屏"。
- **窗口标题跟随活动标签**（`win:set-title` IPC，格式 `标签名 — ShellDesk`）。
- 移除 Electron 默认菜单（`Menu.setApplicationMenu(null)`），消除其 Ctrl+=/-/0 缩放网页、Ctrl+R 重载、F11 与自定义快捷键的冲突；开发者工具改由主进程 `before-input-event` 保留 F12 / Ctrl+Shift+I。

### 3. 标签快捷键（新增，终端聚焦时同样生效）
- 新增 `src/composables/useAppShortcuts.ts` 统一处理：`Ctrl+Tab` / `Ctrl+Shift+Tab` 环绕切换、`Ctrl+1~8` 跳转、`Ctrl+9` 末个、`Ctrl+Shift+W` 关闭标签、`Ctrl+T` 新建终端、`Ctrl+D` 快捷路径、`Ctrl+=` / `Ctrl+-` / `Ctrl+0` 字号缩放、`Ctrl+Alt+B` 侧栏开合。
- **修复历史缺陷**：原来 `onKeydown` 会忽略 `TEXTAREA` 目标，而 xterm 用隐藏 textarea 接收按键，导致终端聚焦时全局快捷键全部失效。现改为放行 `.xterm-helper-textarea`，并在 `TerminalPane.attachCustomKeyEventHandler` 中优先询问同一处理器，已消费的按键不再发往 shell。
- 避让 shell 既有绑定：终端内保留 `Ctrl+W`（PSReadLine 删词）、侧栏用 `Ctrl+Alt+B`（避开 PSReadLine `Ctrl+B` 后移光标；`Ctrl+-` Undo 仍可用 `Ctrl+Z`）。
- `closeTabWithConfirm` 收敛到该模块，App/TabBar/快捷键三处共用同一确认逻辑。

### 4. 侧栏布局
- `Ctrl+Alt+B` 折叠/展开；侧栏与终端之间新增 **4px 拖拽手柄**（180–520px 钳制，双击复位 264px），宽度与可见性经 settings 持久化，通过 `--sidebar-width` CSS 变量驱动。
- 设置面板新增"记住窗口大小/位置"开关与快捷键速查表。
